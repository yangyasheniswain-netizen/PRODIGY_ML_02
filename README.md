# PRODIGY_ML_02

## Customer Segmentation using K-Means Clustering

### Internship
Prodigy InfoTech Machine Learning Internship

### Objective
Create a K-Means clustering algorithm to group customers of a retail store based on their Annual Income and Spending Score.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

### Dataset
Mall Customers Dataset

### Steps Performed
1. Loaded the dataset
2. Selected Annual Income and Spending Score
3. Applied K-Means Clustering
4. Generated customer segments
5. Visualized clusters and centroids

### Output
The model grouped customers into 5 distinct clusters based on purchasing behavior and income.
